# tdm155ai-week-2

TDM 155AI, week 2 (week of 2026-09-14). Working repo for the week's code (JS and Python) and materials.

**Start with the [setup tutorial](_context/tutorial/00-start-here.md).** It takes you from a GitHub account through a package manager, Git, `gh`, ffmpeg, VS Code, and the Claude and ChatGPT desktop apps, to this repo cloned and open on your own machine. The [checklist](_context/tutorial/16-checklist.md) is the one page to tick off before you leave.

Scripts in [`utils/`](utils/README.md) call image and text models through OpenRouter, fal, and Harvard's HUIT gateways (`generate-image`, `generate-text`, `batch-images`, `batch-text`, `stills`, model listers); [`utils/examples.md`](utils/examples.md) is the list of commands verified to work, with dates.

Local-only folders (gitignored): `_media/` for any video, audio, or images you bring in or download, `output/` for everything the scripts generate, `_temp/` for scratch.
