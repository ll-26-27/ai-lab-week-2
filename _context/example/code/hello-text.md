# Hello, text

This is a sample page to replace with a finished class example.

Save this as `hello.js`:

```js
const subject = "week 2";
console.log(`Hello, ${subject}.`);
```

Run it in your terminal with Node.js installed:

```sh
node hello.js
```

Change the subject and run it again. The file is your instruction; the terminal shows the result.
