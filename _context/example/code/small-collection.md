# A small collection

This is a sample page to replace with a finished class example.

```js
const materials = ["a photograph", "a sentence", "a sound"];

for (const material of materials) {
  console.log(`Make something with ${material}.`);
}
```

## Try a variation

Add one material. Remove another. Change the sentence around each item.

This is the beginning of a pattern: write an operation once, then apply it to a collection.
