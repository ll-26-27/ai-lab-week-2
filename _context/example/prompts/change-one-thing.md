# Change one thing

This is a sample page to replace with a finished class example.

Start with a short prompt:

> Describe a room just before someone arrives.

Now change one instruction:

> Describe a room just before someone arrives. Use only sounds.

## Compare the results

- What stayed the same?
- What did the new instruction make possible?
- Which details would you keep?
