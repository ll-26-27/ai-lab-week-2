# Claude Code

**Claude Code is the same Claude, given hands: it can open, edit, and create files in a folder on your computer, and run commands, while explaining what it is doing.**

## In plain terms

Claude in a chat window answers in text. Claude Code is that same model with a different [harness](harness.md) around it, one built to open the files in a folder, edit them, run scripts, and use Git, rather than only produce prose. Think of the difference this way: chatting with Claude is like emailing an expert, you paste things in and text comes back; Claude Code is like that expert sitting at your own desk, working directly in your documents and your terminal.

You reach it two ways: from the terminal directly, or through the desktop app's Code tab, which wraps the same tool in a window with a folder picker and a [permission mode](permission-mode.md) selector. Either way, before it touches anything it usually reads a [CLAUDE.md](claude-md.md) if the folder has one, so it starts already knowing the project's basics.

## Why it matters this term

This is where the tools of the trade point: once a model can see a whole folder, the key skill becomes deciding what is in that folder and what standing notes you leave it, which is context engineering with real stakes.
