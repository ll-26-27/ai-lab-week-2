# Anthropic

**Anthropic is the company that builds Claude, the models behind it, and the apps you use to reach it.**

## In plain terms

Whenever you use Claude, whether on the web, in the desktop app, or through the API in `utils/`, you are using software Anthropic built. Anthropic trains the underlying models (Opus, Sonnet, Haiku) and ships the surfaces around them: the chat app, Cowork, Claude Code, the Chrome extension, and the API.

You do not need to know anything about the company to use the tools well this term. The one distinction worth keeping straight is that "Claude" is the assistant and "Anthropic" is the maker, the same way "ChatGPT" is a product and "OpenAI" is the company behind it. You will see "Anthropic" in billing, in documentation, and as the publisher name when you install the Claude Chrome extension; checking that the publisher says Anthropic before installing anything is good practice.

## Why it matters this term

It is mostly orientation, so the names in menus and documentation are not confusing, and it explains why Claude feels like one consistent assistant across chat, the desktop app, and Claude Code: they are all the same company's models behind different harnesses.
