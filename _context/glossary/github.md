# GitHub

**GitHub is the website where Git repositories live online, so a folder tracked by [Git](git.md) can be shared, browsed, and collaborated on rather than sitting only on one computer.**

## In plain terms

Your personal GitHub account owns your own repositories. An organization is a second kind of owner, shared by a group, with its own repositories and a membership list; this course's is `tdm155ai`. Some repos are public, meaning anyone on the internet can read them, and some are private, visible only to members, which is why joining the course organization is the first step in setup, before a private repo will even show up for you rather than a 404.

Beyond hosting, GitHub adds the parts Git alone does not have: a web interface for browsing files and history, pull requests for proposing and discussing changes, issues for tracking work, and GitHub Pages for publishing a small site straight from a repository, which is how this course's public week-1 repo got its own web address.

## Why it matters this term

Every repository you clone or create this term lives on GitHub first; it is the shared, always-on copy that Git's local history points back to.
