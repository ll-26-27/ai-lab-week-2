# Claude in Chrome

**Claude in Chrome is a browser extension that opens Claude in a side panel next to the page you're on, able to read it and, when asked, click, type, fill forms, and move between tabs.**

## In plain terms

It needs Google Chrome specifically, not Safari, not other Chromium browsers, and a paid Claude plan. Install it from the Chrome Web Store, check the publisher says Anthropic, then pin it and sign in the same way as the desktop app. Once open, it can simply read the current page and answer about it, no pasting required, or it can act: navigate, click, type, and fill forms across tabs when you ask it to do something rather than tell you something. It asks before acting on a site the first time and confirms anything it treats as consequential.

The permissions Chrome lists at install, reading and changing site data, controlling the browser, managing tabs, are an honest description of what the tool can do, which is also why the same page can be hijacked by hidden instructions written into it, see [prompt injection](prompt-injection.md). Keep confirmations turned on, and never use it on a bank, an email account, or anything logged in as you that you would not hand to a stranger.

## Why it matters this term

It is the browser rung of the "how much reach does this agent have" ladder this course climbs: files in a folder, then a browser, then, with computer use, the whole screen.
