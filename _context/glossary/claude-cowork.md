# Claude Cowork

**Cowork is a tab in the Claude desktop app where Claude works on the actual files in a folder you connect, rather than only on what you paste into a chat.**

## In plain terms

In a plain chat, Claude only sees what you paste or attach, and whatever it produces comes back as text you copy out by hand. In Cowork, you point Claude at a folder and it works on the files there directly: reading a stack of images, renaming them, pulling text out of them, writing new files. The button even changes from "new chat" to "new task" to mark the shift from talking to doing.

A few things worth holding onto: Cowork runs in a contained space, it can only see folders you have explicitly connected, and it shows you a plan plus the files it is touching as it goes, rather than working silently. Whether it can only read files or also change them is something you grant. And because the power and the risk are the same fact, it can touch your files, pointing it at Downloads or Desktop is a fine demo and a poor habit; a dedicated project folder is safer, see [data sensitivity](data-sensitivity.md).

## Why it matters this term

It is the leap from "the model generates text" to "the model does things to my stuff," which is exactly the shift that Claude Code takes further, with the terminal and Git added.
