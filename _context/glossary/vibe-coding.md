# Vibe coding

**Vibe coding is letting an AI agent write and run code from a plain-language description, judging the result by whether it works rather than by reading every line.**

## In plain terms

Traditional coding means writing and understanding each line yourself. Vibe coding, a term that spread widely through 2025, describes the looser mode this course's tutorials use for the batch and multiplication activities: you tell Claude Code or Codex what you want in ordinary English, it writes and runs the code, and you check the outcome, the image that appeared, the number that came back, rather than auditing the script line by line.

It is a real and useful mode, not a shortcut to feel bad about, but it comes with a real trade-off: the less you read, the more you are trusting the agent's judgment on things you cannot spot-check. The habits that make it safer are the ones already in this glossary: start in [plan mode](plan-mode.md) for anything new, keep the [permission mode](permission-mode.md) tight until you have watched the agent succeed a few times, and read the parts that touch anything you would mind losing, your `.env`, your Git history, a real dataset, even if you skim the rest.

## Why it matters this term

Most of this course happens in exactly this mode, describing a task to Claude Code or Codex and checking the output, so knowing what you are and are not verifying is worth being honest about early.
