# ffmpeg

**ffmpeg is a command-line tool for working with audio and video: converting formats, trimming clips, checking a file's length, and far more, all without opening an editor.**

## In plain terms

Where a video editor is a program with windows and buttons, ffmpeg is a single command you run in the [terminal](terminal.md), naming the input file, what you want done, and the output file. You will not learn its full syntax this term, most people never do, but you will install it and use it once, to make a short test clip, which confirms both that it is on your machine and that your terminal can find programs installed by the package manager.

It matters past this one exercise because so many tools this course touches on, video generation, transcription, media processing scripts, ultimately call ffmpeg underneath a friendlier interface. Recognizing the name means you will know, later, that "this script needs ffmpeg installed" is a real and normal requirement, not a strange one.

## Why it matters this term

It is the checklist item that proves your package manager works end to end, and it quietly underlies a large share of the audio and video tooling you will meet later.
