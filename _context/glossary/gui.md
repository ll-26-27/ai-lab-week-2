# GUI (graphical user interface)

**A GUI is the buttons-menus-and-windows way of using a program: you click, it acts, and the program decides what you are allowed to click.**

## In plain terms

Nearly everything you have done on a computer was through a GUI: the chat window, the desktop app, the browser, the Finder. It is the easiest way to start using something, because the interface shows you what is possible. It is the hardest way to repeat something, because every action is a click that leaves no record you can rerun: twenty images means twenty clicks, and an agent cannot press buttons for you the way it can type commands.

The other two ways of talking to a program are the [CLI](cli.md), where you type commands, and the [API](api.md), where one program talks to another with no person involved. This course moves through all three in that order.

## Why it matters this term

Knowing the word makes the trade visible: the GUI you are comfortable in is the layer someone else designed, and the same program usually has a command-line or API door underneath it that you can open yourself.
