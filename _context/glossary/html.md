# HTML

**HTML is what every web page is made of; it gives a document real layout and behavior, not just structure.**

## In plain terms

[Markdown](markdown.md) gives you clean text with light formatting: headings, bold, lists. HTML (HyperText Markup Language) is the step up, letting a document have columns, cards, collapsible sections, a search box, buttons that do something, and colors you control. Markdown is a tidy typed page; HTML is a small web page.

Why you would ask for HTML output specifically: more visual structure when information is hard to scan as plain text, real interaction (links between pages, a filter box, a sortable table), a file that opens in any browser with no app or install, and one linked stylesheet that restyles a whole set of pages at once. You do not usually write it yourself; you describe what you want ("turn these notes into a browsable page with an index and a search box") and Claude Code or a script produces the files. The skill is still [context engineering](context-engineering.md): say who it is for and how it should behave.

## Why it matters this term

The `index.html` a batch script produces, `output/batches/<run>/index.html`, is HTML for exactly this reason: a grid you can scan by eye, in a browser, with no other tool needed.
