# Claude: web, desktop, command line

**Claude reaches you through three interfaces: the website, the desktop app, and the command line. Same model each time; what changes is what it can reach and how much of its work you can see.**

## In plain terms

**Web (claude.ai)** runs in your browser on Anthropic's servers. It can see what you paste or upload, and you see the conversation. Best for questions, drafts, and thinking out loud.

**The desktop app** is a Mac or Windows program with the same chat plus two more tabs. [Cowork](claude-cowork.md) connects a folder and shows work as tasks; **Code** opens a folder and runs [Claude Code](claude-code.md) inside a window, with a folder picker and a [permission mode](permission-mode.md) menu. Best for working on your own files with a familiar front.

**The command line** is the `claude` command in the [terminal](terminal.md). It is the same Claude Code as the desktop app's Code tab, without the window: it can reach everything in the folder and every command-line tool on your machine, and you see every command it runs and every file it edits, as text. Best for building, batching, and repeating things with scripts.

Each is a different [harness](harness.md) around the same engine. In this course we use the desktop app's Code tab most, because it gives Claude the same hands as the terminal behind a friendlier front, and drop to the terminal when we want to see everything.

## Why it matters this term

Choosing the door is a real decision each time: how much should Claude be able to reach, and how much of its work do you want to watch.
