# Markdown

**Markdown is plain text where a handful of symbols, `#`, `-`, `**`, backticks, turn into formatting when displayed, and read fine even when they don't.**

## In plain terms

You have used formatted documents your whole life; Markdown gets the same result with a different method. Instead of clicking a bold button, you type `**important**` and it renders as **important**; `# Heading` becomes a large heading; `- item` becomes a bullet; `[Bok Center](https://bokcenter.harvard.edu)` becomes a clickable link. The dozen marks that cover most of it: headings with `#`, bold with `**`, italics with `*`, lists with `-` or `1.`, links with `[text](url)`, code in backticks, and tables with pipes and dashes.

The point of all this is that a Markdown file is just a text file. It opens on any computer, never gets corrupted by a program update, and is perfectly readable even before anything renders it. That is why nearly everything a model reads and writes, this glossary, every `CLAUDE.md` and `AGENTS.md`, every README on GitHub, is Markdown. You do not need to memorize the symbols; you can ask Claude to write Markdown for you. The goal is just to recognize it, so `#` and `*` register as formatting, not confusion.

## Why it matters this term

Almost everything you create and read in Claude Code, Codex, and this glossary is Markdown. Knowing "oh, that's just formatting" removes a common early source of confusion.
